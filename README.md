# MORO PWA

Inventory management for ALAKER SWEETS: an installable web app (PWA) for desktop and phone,
backed by Google Sheets through a Google Apps Script web app.

- `app/` – the PWA (static files, hosted on GitHub Pages)
- `server/` – Apps Script web app (data API over Google Sheets)
- `migration/` – one-time migration from the MORO v13 Excel workbook

No business data is stored in this repository. Data lives only in the private Google Sheet.

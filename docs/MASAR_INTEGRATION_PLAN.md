# دمج دورة طلبيات مسار داخل MORO

> تحديث 2026-11-03. الخطة الأولى (2026-10-16) كانت **ربط** MORO بمسار عبر واجهة خادم لخادم، ونُفِّذت مرحلتها الأولى (المواد الأولية).
> بعدها تقرر **دمج** دورة الطلبية نفسها في MORO، فيعمل الكاشير والتوزيع والأقسام والمخازن والسائق من MORO وحده.
> نص الخطة الأولى محفوظ في سجل git لهذا الملف.

## القرارات المعتمدة

- MORO هو **المرجع الوحيد للمخزون**، وفيه تُنشأ المواد كلها.
- دورة الطلبية تُبنى في MORO: الكاشير ← التوزيع ← الأقسام والمخازن ← الرحلة والسائق ← استلام الكاشير ← الفاتورة.
- الرصيد يُحجز عند الاعتماد حسب ترتيب الاعتماد، ويُخصم حين **يسلّم القسم أو المخزن للتوزيع**، لا عند تحميل السائق.
- النشر: كل المراحل على نسخة التطوير (MORO DIV) أولًا، ثم نشر واحد على الإنتاج بعد انتهاء التجربة وبموافقة صريحة.

## ما بُني (على DIV، حتى 0.9.114)

| المرحلة | ما يعمل |
|---|---|
| الطلبية | الكاشير (بوردية) يكتب مسودة ويرسلها لليوم التالي. يختار المواد من مخزن أو قسم بقائمتين قابلتين للبحث. |
| الاعتماد | التوزيع يعتمد أو يرفض. الأسطر تذهب إلى قسمها الإنتاجي أو مخزنها. |
| التجهيز | كل قسم أو مخزن يرى أسطره فقط: تسليم كامل أو جزئي أو "غير متوفر" بسبب. الإنتاج بلا وصفة للمنتج النهائي. |
| الناقص | التوزيع يقبل ما سُلّم ويغلق الباقي (إغلاق الناقص). |
| الرحلة | التوزيع ينشئ رحلة بترتيب المحلات. السائق يرى حمولة كل محل والرحلة كاملة، ويحمّل الكل قبل أي تسليم، ويؤكد إن سلّم خارج الترتيب. |
| الاستلام | الكاشير يستلم ويذكر سبب كل نقص. التوزيع يراجع الفرق لكل سطر (إرجاع إلى المخزن أو تالف) قبل الفاتورة. |
| الفاتورة | فاتورة لكل طلبية من المستلَم، بأسعار مجمّدة، في قسمين (منتج نهائي ومواد المخزن). تبويب الانتظار يعرض لكل مادة: طُلب، سُلّم، استُلم. أربعة تقارير للطلبيات. |
| الإشعارات | إشعار هاتف لكل خطوة، وأرقام على القوائم والتبويبات. |
| الأمان والدقة | قراءة الجداول من جديد داخل القفل (لا رقمين متطابقين)، ورسالة واضحة لطلبية تصرّف فيها غيرك، وأمر للقراءة فقط في جدول البيانات: MORO ← Check for duplicate numbers. |

## ما بقي

1. **الطلبيات الخاصة** (موجودة في مسار، لم تُبنَ في MORO): موعد تسليم يحدده الكاشير، مكان تسليم آخر غير المحل، ملاحظات ومرفقات، وصنف خارج الكتالوج (شراء أو تصنيع). تحتاج قرارات قبل البناء.
2. **مرتجعات المحل والحجر الصحي** (موجودة في مسار): الكاشير يُرجع بضاعة، تدخل الحجر، ثم يقرر مدير الإنتاج لكل صنف: متاح أو تالف أو منتهي. تحتاج قرارات قبل البناء.
3. **النشر الواحد على الإنتاج**: نسخة احتياطية لجدول الإنتاج، ثم النشر، ثم ترقية الجداول (الإصدار 33)، ثم مصير دورة الطلبية في مسار.

## ما يحتاج تدخلك مرة واحدة

- الموافقة على النشر بكلمة "انشر".
- تشغيل ترقية الجداول بعد النشر إن طُلبت.
